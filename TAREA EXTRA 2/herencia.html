Programación II — Herencia

Ejercicio

Dadas las siguientes clases:

● Gato ● SerVivo ● Conejo ● Adulto ● Planta ● Vivora ● Felino ● Rana ● Niño ● Reptil ● Humano ● Flor ● Ratón ● León ● Roedor ● Animal ● Anciano

a. Organizar las clases y dibujar el diagrama en una jerarquía válida indicando claramente los niveles de herencia.
b. Identificar en cada clase de 1 a 3 atributos significativos.

a) Diagrama de jerarquía

Las clases se organizan en una estructura arbórea lógica, comenzando desde la clase raíz general SerVivo hacia las ramificaciones biológicas y sociales específicas.

b) Atributos Significativos

Modelado de variables de instancia con sus especificaciones requeridas:

SerVivo

  • + nombre : str
  • + edad : int
  • + estado : str

Animal

  • + peso : float
  • + alimentacion : str
  • + habitat : str

Planta

  • + altura : float
  • + tipo : str
  • + necesita_luz : bool

Humano

  • + nombre_completo : str
  • + profesion : str
  • + nacionalidad : str

Felino

  • + color_pelaje : str
  • + tiene_garras : bool
  • + longitud_colmillos : float
